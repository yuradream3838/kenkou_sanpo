# 発見ノート

散策中に偶然見つけたものを、**調べて記録する** PWA（スマホのホーム画面に追加できる Web アプリ）。

経験値は歩いた距離ではなく **「どれだけ深く調べたか」** で増えます。

| 段階 | 条件 | XP |
|---|---|---|
| 見つけた | 写真・場所・名前のどれかを記録 | 10 |
| 気づいた | 「気になったこと」か「仮説」を記入 | 20 |
| 調べた | 「調べて分かったこと」を記入 | 30 |
| 裏付けた | 調べた内容＋出典を1件以上 | 50 |

図鑑に新しいカテゴリを登録すると +30 XP。

## 機能

- 発見の記録：写真（1つの発見に10枚まで、撮影 / ファイルから複数選択、表紙の選択）、カテゴリ（25種）、日時、場所、気づき、仮説、調査結果、出典、確信度
- 地図：国土地理院タイル（淡色 / 標準 / 航空写真 / 色別標高図 / 陰影起伏図 / 昔の航空写真 1945〜50年・1961〜69年）上に発見を表示
- 発見図鑑：グループ別に表示。各種類に「探し方ガイド」（見つけやすさ・見分けるポイント・探す場所・地図で探すコツ）
- 気持ちタグ（きれい・なつかしい・ふしぎ など）と「こころの記録」
- レベル・称号・統計（発見数、探索日数、裏付け済み数）
- おでかけ：散策のスタート駅をランダムに決める（神奈川県 347 駅）
  - 「距離で選ぶ」：現在地または指定した駅から、最短〜最長 km の範囲で抽選
  - 「県内どこでも」：県内の全駅から抽選
  - 「駅を選ぶ」：行きたい駅を自分で指定（履歴の「もう一度行く」からも）
  - いまのおでかけ：行き先・目的（お題）・移動中／散歩中の状態・このおでかけの発見を常に表示。発見は自動でおでかけに紐づく
  - 「着いた！散歩を始める」で散歩開始、「帰る」で散歩終了（散歩時間を記録）。途中に時刻つきのひとことメモを残せる
  - 散歩の記録：開始・メモ・発見・終了を時刻順に表示（履歴からも振り返れる）
  - 行き方を調べる：駅の座標で Google マップ（iPhone では Apple マップも）の電車経路を開く
  - 路線でしぼる（複数選択可）、乗り換えなしで行ける駅だけ（基準の駅／現在地の最寄り駅と同じ路線）
  - 一度出た駅を、その後 N 回の抽選で出さない設定（なし / 1〜50 回）
  - 行った駅を除外、今日のお題（図鑑の未登録カテゴリ）、駅コレクション（行った駅 / 全駅）
- データの書き出し / 読み込み（JSON、写真・おでかけ履歴込み）
- オフライン対応（Service Worker）、更新の自動反映
- 更新履歴（設定 → 更新履歴）と、更新後の初回起動時のお知らせ

## プライバシー設計

- データはすべて端末内（IndexedDB）に保存。サーバーへの送信なし
- 位置情報はボタンを押したときのみ取得
- 写真は Canvas で再エンコードし EXIF（撮影位置など）を削除
- 詳細は `privacy.html`

## 構成

ビルド不要の静的サイトです。

```
index.html            画面の骨組み
css/style.css         スタイル（ダークモード対応）
js/app.js             画面・ルーティング
js/db.js              IndexedDB
js/categories.js      図鑑カテゴリ・探し方ガイド・気持ちタグ（ここを編集すれば種類を増やせる）
js/progress.js        経験値・レベル・称号
js/image.js           写真の縮小と EXIF 除去
js/map.js             地図（Leaflet + 国土地理院タイル）
js/go.js              おでかけ（行き先の抽選・いまのおでかけ・駅コレクション）
js/trip.js            おでかけの状態（移動中・到着・終了）と経路リンク
js/stations.js        駅データの読み込み・距離計算・抽選
data/stations/14.json 神奈川県の駅一覧（tools/build_stations.py で生成）
sw.js                 Service Worker
vendor/leaflet/       Leaflet 1.9.4（BSD-2-Clause）
privacy.html          プライバシーポリシー（下書き）
```

## 駅データ

`data/stations/14.json` は「国土数値情報（鉄道データ）令和6年度 国土交通省」を加工して作成しています。
同じ駅名で 800m 以内の駅（乗換駅）は 1 駅にまとめています。

再生成・他県の追加:

```bash
python3 -I tools/build_stations.py N02-24_Station.geojson japan.geojson 14 data/stations/14.json
```

- `N02-24_Station.geojson`：[国土数値情報 鉄道データ](https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N02-2024.html) の駅データ
- `japan.geojson`：都道府県境界（[dataofjapan/land](https://github.com/dataofjapan/land)、地球地図日本ベース）。県内判定にのみ使用し、リポジトリには含めない
- JR の正式路線名（例：東海道線）は実際の列車の系統（東海道線・京浜東北線・横須賀線…）に分けている（スクリプト内の `SERVICE_ROUTES`）
- 境界付近で判定がずれる駅は、スクリプト内の `OVERRIDES` で補正する（出力に境界付近の駅一覧が出るので確認に使う）
- 他県を追加したら `js/stations.js` の `PREFECTURES` に登録する

## ローカルで動かす

```bash
python3 -m http.server 8000
```

ブラウザで http://localhost:8000 を開く。位置情報と Service Worker は `localhost` か HTTPS でのみ動作します。

## 公開（GitHub Pages）

1. リポジトリの Settings → Pages
2. Source を「Deploy from a branch」、ブランチとフォルダ `/ (root)` を選択
3. 表示された `https://<ユーザー名>.github.io/kenkou_sanpo/` をスマホで開き、「ホーム画面に追加」

公開前に `privacy.html` の運営者情報・連絡先を記入してください。
アプリを更新したら `js/changelog.js` の先頭に更新履歴を追記し（これがアプリのバージョンになる）、`sw.js` の `VERSION` も同じ番号に上げてください。
